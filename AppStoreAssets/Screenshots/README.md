# Kutyajó matek – App Store screenshots

Source design: Figma › Kutyajo matek › "App Store Screenshots – iPhone 6.9"" section.
Spec: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/

Upload order: 01 → 02 → 03. All files are PNG, sRGB, no transparency.

| Folder | Size | App Store Connect slot | |
|---|---|---|---|
| `iPhone-6.3/` | 1206×2622 | iPhone with Dynamic Island – medium (6.1"/6.3") | **REQUIRED** |
| `iPhone-6.1/` | 1179×2556 | same slot, alternative size | use if 6.3 is rejected |
| `iPhone-6.9/` | 1290×2796 | iPhone with Dynamic Island – large (6.7"/6.9") | optional |
| `iPhone-6.5/` | 1284×2778 | iPhone with Face ID – large (6.5") | optional |

Each slot accepts only its own sizes. Uploading a large-display image into the medium slot gives "invalid dimensions".

The phone screens are real captures from the iPhone 17 Pro Max simulator, using a demo profile ("Bori").
