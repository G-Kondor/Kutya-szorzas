Spec: https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications/
Source design: Figma › Kutyajo matek › "App Store Creative Assets – Header & Search results (iOS 27)".

| File | Placement | Aspect ratio | Size |
|---|---|---|---|
| `header-21x9-3840x1646.png` | Product page header | 21:9 | 3840×1646 |
| `search-results-3x2-3840x2560.png` | Search results | 3:2 | 3840×2560 (maximum allowed) |
| `universal-16x9-5244x2950.png` | Header or search results, 16:9 option | 16:9 | 5244×2950 |

All files are PNG, sRGB, with no alpha or transparency.

The header has no text and keeps its focal point in the center, so device crops don't cut anything important.
The search results and 16:9 assets carry a Hungarian headline. Make an English version for the English listing.

Check each one with the Preview tool in App Store Connect before going live.
